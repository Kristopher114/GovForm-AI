👥 How Anyone (You or Your Friend) Can Host Their Own OCR Server

  1. 1. Start Desktop Python OCR Server: 
    python local_ocr_server.py
  2. 2. Launch Cloudflare Tunnel: 
    cloudflared tunnel --protocol http2 --edge-ip-version 4 --no-prechecks --url http://localhost:8000
  3. 3. Publish to Mobile App: Paste the generated https://...trycloudflare.com URL into the box above and click 🚀 Publish to Mobile App!
  4. 4. In the Mobile App (Two Ways to Connect):
    • Automatic Cloud Sync: In your mobile app's .env file, set EXPO_PUBLIC_SUPABASE_URL and EXPO_PUBLIC_SUPABASE_ANON_KEY (or EXPO_PUBLIC_FIREBASE_PROJECT_ID). The phone updates automatically!
    • Direct In-App Paste (Instant): In the mobile app, tap Settings → Server 1 Endpoint, paste the tunnel URL directly into the box, and tap Save & Connect.

⚙️ Cloud Sync Configuration

Paste your Project URL & Anon Key from Supabase Console > Project Settings > API.

SQL TO CREATE TABLE (Run once in SQL Editor): 
create table if not exists server_config (
  id int primary key default 1,
  desktop_url text not null,
  updated_at bigint not null,
  source text default 'pc_portal'
);
alter table server_config disable row level security;
